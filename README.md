# Eco Adventure VR

Eco Adventure VR is an interactive virtual reality experience built with A-Frame, designed to teach and engage users with environmental puzzles and nature-themed models.

## Features
- Immersive VR scene with realistic sky, ground, and ambient sounds
- Two main puzzles:
  - **Fire Puzzle:** Extinguish the fire using water from the bucket
  - **River Puzzle:** Solve the boulder sequence to let the river flow
- Interactive flower models (Sunflower, Roses, Flower Pot, etc.)
  - Click or hover to view educational popups with information
- Play and Hint buttons to control puzzle start and get hints
- 3D models and textures for landscape, flowers, boulders, and more

## Controls
- Use mouse or VR controller to interact with clickable objects
- Click the Play button to start puzzles
- Click the Hint button for puzzle hints
- Click or hover over flowers to see information popups
- Use WASD or fly controls to move the camera (if enabled)

## Educational Content
- Sunflower: Common Name, Scientific Name, Description
- Roses: Common Name, Scientific Name, Description
- Flower Pot: Description of plant structure
- More flowers and nature models included

## Technologies Used
- [A-Frame](https://aframe.io/) for VR scene and interactions
- 3D models in GLB/FBX format
- Custom JavaScript components for puzzles and popups

## How to Run
1. Open `index.html` in a WebVR-compatible browser
2. Make sure all assets (models, images, sounds) are in the correct folders
3. Interact with the scene using mouse or VR headset
